# Release checklist

- [ ] Version updated in VERSION, package.json and manifest.json.
- [ ] CHANGELOG updated.
- [ ] `npm run verify` passes.
- [ ] Extension loads without errors in Chrome.
- [ ] Side panel opens.
- [ ] One matrix can be generated.
- [ ] Local result is written to IndexedDB.
- [ ] CSV export works.
- [ ] M&M adapter tested manually when changed.
- [ ] Human verification is never bypassed.
- [ ] Google Sheets sync tested when sync code changes.
- [ ] Release ZIP built and copied to `releases/`.
